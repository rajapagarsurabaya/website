# Website Raja Pagar Surabaya

- Panel admin: https://rajapagarsurabaya.netlify.app/admin
- Konten yang diedit lewat panel admin: `content/proyek` (galeri) dan `content/artikel` (blog)
- Foto proyek dan foto artikel: `static/img/proyek`
- Netlify membangun website otomatis dengan `python3 build/gen.py prod` setiap kali "Publish Changes" diklik di panel admin.
- Desain, halaman layanan, dan teks beranda ada di folder `build/` (dikerjakan tim, jangan diubah dari panel admin).
